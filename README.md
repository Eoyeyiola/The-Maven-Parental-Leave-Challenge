# Family Leave Challenge Dashboard (Maven Analytics)

**Project Type**: Data Analytics | Power BI  
**Topics**: Parental Leave, HR Analytics, Industry Benchmarking  

## Overview
This dashboard analyzes paid parental leave policies across **1,600+ companies and 46 industries**, highlighting disparities between maternity and paternity leave using interactive visualizations.

Built for the [Maven Family Leave Challenge](https://www.mavenanalytics.io/), this project focuses on:

- Paid vs. unpaid leave trends by industry
- Top and bottom performing sectors
- Gender-based policy gaps
- Key metrics: average days, industry comparisons, and company policies

## Tools Used
- Power BI (DAX, Drillthroughs)
- Excel (Data Cleaning, Category Grouping)

## Key Insights
- Technology leads in paid leave equity for both parents.
- Major gaps exist in paternity leave across most industries.
- Certain industries like Utilities and Printing offer little to no paid leave.

## Highlights
- Built an "Industry Category" feature for consistency.
- Created KPIs & slicers for stakeholder-level filtering.
- Published to [NovyPro](https://www.novypro.com/project/leave-analysis).
